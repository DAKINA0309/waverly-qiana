仲夏·芳园

2025

第二颗太阳 · The Second Sun

当太阳仍在燃烧，光却再也无法抵达地球。

Project Overview

项目类型

AI 科幻漫剧 / AI 剧情概念短片

时长

90 秒

制作周期

7 天

我的职责

导演 / 编剧 / AI 视觉设计 / 后期制作

使用工具

ChatGPT, Midjourney, ComfyUI, 小云雀, LibTV, 即梦, Premiere Pro, After Effects

交付形式

90 秒 AI 科幻剧情短片

Story & Concept

从长篇世界观中提炼一条 90 秒悬念主线

作品改编自原创长篇科幻 IP《第二颗太阳》，从完整世界观中提取"太阳熄灭、月亮异变、父亲失踪"三条核心线索。故事发生在公元 2179 年，太阳依然存在，却有一股未知力量阻止阳光抵达地球。全球陷入极寒永夜，异常明亮的月亮被人类视为最后的救赎——天文台守望者林昼却发现：月光并非希望，而是一场持续了数十亿年的监视。

情绪基调：压迫、悬疑、孤独、理性、被观看的不安。

Script Breakdown

从长篇科幻文本中提取关键人物（林昼、林鹤洲、幼年林昼）、核心场景（天文台、地下资料室、冰封城市）和情绪节点。采用非线性冷开场结构：先展示警示笔记，再回溯灾变过程，最后回归月光——让观众从第一秒就带着"为什么不能相信月亮"的问题进入故事。

Storyboard Design

01
景别极近特写 运镜静止 + 呼吸式推进 情绪静默 / 不安 / 被观察 内容泛黄笔记，"如果月亮开始发光，不要相信它。"冷白月光如扫描线扫过
02
景别全景 · 24mm 广角 运镜轨道横移绕半圈 情绪孤独 / 冷静 / 未知逼近 内容林昼站在破碎天文台圆顶下，月光从穹顶切入，人物渺小
03
景别特写 · 85mm 运镜匹配剪辑，门洞形接门缝 情绪创伤 / 无力 / 记忆回返 内容幼年林昼躲在门后，只露出一只眼睛，目睹父亲被带走
04
景别主观远景 + 300mm 超长焦 运镜穹顶上仰 → 月面特写 情绪压迫 / 注视 / 悬念封口 内容穹顶眼眶式构图，异常明亮的月亮如眼睛回看地球

Character & Visual Design

从人物功能出发设计角色：林昼（冷峻研究者，凌乱黑发/苍白肤色/旧式极寒防护服）、年轻林鹤洲（温和理性、白色科研服、隐藏恐惧的眼神）、幼年林昼（门缝遮挡构图、含泪却倔强的眼睛）。通过身份锚点、Prompt 拆解和多视角迭代确保角色在不同镜头中的视觉连续性。

AI Production Pipeline

故事策划→ 剧本拆解→ 分镜设计→ 角色设定→ AI 图像生成→ AI 视频生成→ 后期剪辑→ 声音设计→ 最终成片

Challenges & Solutions

角色一致性控制

通过多视图设定图、固定 Prompt 模板和跨镜头对比，确保林昼在不同景别和时间线中保持视觉连续。

镜头连续性

分镜表中明确标注视线方向、动作衔接和道具位置，保障 AI 生成素材可进入后期剪辑。

动作稳定性

对人物漂移和动作失真的镜头重新生成与多轮筛选，保留符合物理逻辑的动态画面。

画面风格统一

固定低饱和蓝黑色调、统一的光线方向和材质质感，在 Premiere 中进一步做色彩匹配。

AI 素材二次剪辑

不直接使用 AI 生成镜头的原始顺序，而是按照电影剪辑思维重新组织节奏和转场。

音画节奏控制

通过低频心跳、风雪声和声音桥建立悬疑氛围，声音先于画面进入，增强沉浸感。

Production Stills

项目复盘

《第二颗太阳》是我在 AI 漫剧方向的一次完整导演方法实践。在 7 天内将长篇科幻文本压缩为 90 秒剧情结构，通过人物关系、视觉母题、非线性剪辑和镜头设计建立悬念，同时完成从角色设定、Prompt 设计、AI 动态生成到后期剪辑与声音设计的全流程。项目验证了"剧本改编—分镜设计—AI 视觉控制—全流程交付"的能力闭环，也让我更清晰地认识到：AI 工具的核心价值不在于生成单张漂亮画面，而在于如何用导演思维组织、筛选和控制生成结果，使其服务于叙事。

暗恋

有些喜欢，藏在每一次看似不经意的靠近里。

Project Overview

项目类型

校园青春剧情短片

时长

3分40秒

制作周期

7 天

我的职责

导演 / 编剧 / 后期制作

使用工具

Premiere Pro, 剪映, Photoshop

交付形式

3分40秒真人剧情短片

Story & Concept

以"双向暗恋"为核心，围绕转校生 A 与同班同学 B 展开。A 总以念叨和管束的方式隐藏喜欢；B 看似被动，却在 A 胃疼时偷偷送药、在对方离开时默默整理书桌。一次意外的"表白练习"和一张写满攻略计划的纸条，让未说出口的心意逐渐浮出水面。

情绪基调：真实、轻松、克制、暧昧。自然光、校园感、生活化、青春留白。

Director's Vision

采用递进式短剧结构：日常关系建立 → 表白练习制造乌龙 → 送药补充隐藏情感 → 攻略纸条揭开真相 → 追出教室开放式收尾。核心导演策略是用行为和细节代替直白告白——台词可以装作不在意，但眼神和动作必须暴露真实情绪。

Storyboard Design

01
场景练习表白被撞见 设计A 独自练习 → B 画外进入 → 戛然而止 情绪意外 / 尴尬 / 暧昧
02
场景对着我练习 设计B 让 A 对着自己练 → A 反问 → B 局促失语 情绪试探 / 拉扯 / 心动
03
场景送药 设计药盒落桌特写 + B 故作平静 情绪克制 / 关心 / 口是心非
04
场景发现攻略纸条 设计过肩 → 纸条特写 → 闪回 → B 冲出门 情绪恍然大悟 / 情感确认
05
场景追出教室 设计手持跟拍 → B 叫住 A → A 回头 → 对视留白 情绪急切 / 释然 / 心动留白

Production Pipeline

剧本创作→ 分镜设计→ 演员确认→ 排练走位→ 实景拍摄→ Premiere 剪辑→ 声音设计→ 最终成片

Production Stills

项目复盘

《暗恋》让我完成了从文字剧本到真人影像的完整导演实践。在有限时长内建立人物、铺垫情感并完成双向暗恋的剧情闭环。核心收获是：细腻的情绪并不依赖大量台词，而来自人物行为、演员反应与镜头节奏的共同作用。

仲夏·芳园

在一方荷塘与八雅文化之间，重新发现乡村生活的诗意。

Project Overview

项目类型

国风文旅影像 / 乡村文化传播

时长

2 分钟

制作周期

7 天

我的职责

编导 / 策划统筹 / 视听设计 / 拍摄执行 / 后期剪辑

使用工具

Premiere Pro, Photoshop

项目成果

第六届国际大学生旅游文创设计大赛 · 数字媒体类铜奖

Story & Concept

以海口芳园国际艺术村为拍摄对象，将"琴、棋、书、画、诗、酒、花、茶"八雅文化作为内容线索，通过荷塘栈道、乡村民宿、汉服体验和艺术研学等场景，呈现芳园村自然、人文与产业融合的独特气质。核心主题：文化不只是被保存的传统，也可以成为乡村更新与产业发展的动力。

叙事核心不是"介绍景点"，而是带领观众从城市快节奏中抽离，进入一个由自然、传统文化和乡村生活共同构成的东方审美空间。

Narrative Structure

采用三段式递进结构：

第一阶段｜风光入境——荷塘、栈道、村落建筑，慢节奏空镜建立宁静雅致基调。

第二阶段｜人文体验——人物进入画面，汉服、民宿、艺术研学，从"观看景物"转向"进入生活"。

第三阶段｜价值升华——文旅业态与艺术乡村定位呈现，传递文化赋能乡村振兴的主题。

Storyboard Design

01
镜号仲夏入园 · 大全景 运镜缓慢推进 / 轻微横移 情绪宁静 / 开阔 / 初见 内容芳园村整体空间 + 大片荷塘，人物未出现，环境先建立气质
02
镜号漫步荷塘 · 全景转中景 运镜侧向跟拍 / 背后跟拍 情绪松弛 / 沉浸 / 清雅 内容人物沿栈道行走，栈道作为引导线，人物位于三分之一处
03
镜号汉服与八雅 · 中景 + 细节特写 运镜人物中景 → 特写切换（衣袖/茶具/书页） 情绪雅致 / 细腻 / 东方意境 内容通过服装、器物和动作表现传统文化，动作匹配剪辑
04
镜号民宿与研学 · 空间全景 + 人物中近景 运镜推门/穿廊动作完成场景转换 情绪生活感 / 温度 / 文化体验 内容庭院、艺术空间和研学活动，从"看风景"转向"体验生活"
05
镜号人与村落共生 · 远景 / 大全景 运镜稳定长镜头 / 缓慢拉远 情绪舒展 / 余韵 / 希望 内容人物融入芳园村环境，完成主题升华

Production Pipeline

文化调研→ 主题策划→ 分镜设计→ 场地确认→ 实景拍摄→ Premiere 剪辑→ 色彩统一→ 声音设计→ 最终成片

Production Stills

项目复盘

《仲夏·芳园》让我完成了从地方文化调研到文旅影像表达的完整实践。在 7 天内独立完成前期策划、主题提炼、分镜设计、场地确认、实景拍摄、视听编排与后期剪辑。作品获得第六届国际大学生旅游文创设计大赛数字媒体类铜奖。核心领悟：优秀的文旅内容不是对景点的简单罗列，而是通过镜头重新建立观众与一片土地之间的情感关系。
